# Spa Business Manager

ไฟล์สำหรับนำขึ้น GitHub Pages

## วิธีอัปโหลด
1. แตกไฟล์ ZIP นี้ก่อน
2. เปิด Repository ของโปรเจกต์ใน GitHub
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปไว้ที่ root ของ Repository (อย่าอัปโหลด ZIP อย่างเดียว)
4. ตรวจสอบว่า `index.html`, `manifest.webmanifest`, `sw.js` และไฟล์ไอคอนอยู่ระดับเดียวกัน
5. ไปที่ Settings → Pages แล้วเลือก Deploy from a branch → main → /(root) → Save

## หมายเหตุ
- ข้อมูลแอปยังเก็บใน Local Storage ของเบราว์เซอร์/อุปกรณ์แต่ละเครื่อง
- การใช้หลายเครื่องร่วมกันยังต้องเพิ่มฐานข้อมูลออนไลน์และระบบล็อกอินในภายหลัง
